# PlayerCollars Forge

PlayerCollars Forge lets players wear pet collars in **Minecraft 1.18.2**.

This release is for **Minecraft Forge 40.x** and requires:

- [Curios API 1.18.2](https://www.curseforge.com/minecraft/mc-mods/curios)
- [Java 17](https://adoptium.net/temurin/releases/?version=17)

Kawaii Dishes is an optional compatibility dependency.

## Features

- Wearable collars using the Curios `necklace` slot
- Owner assignment and owner-only leash mechanics
- Collar dye and paw-color customization
- Mending, Loyalty, Thorns, and Binding Curse support
- Clickers that turn nearby owned players toward the owner
- Optional Kawaii Dishes compatibility for binding-curse items
